# Часть 1. Знакомство с pthread (Оценка 3)

## Описание выполненной работы
В рамках данной части были изучены и применены базовые функции библиотеки `pthread`:
1. **Создание потока:** Использована функция `pthread_create()` с атрибутами по умолчанию.
2. **Ожидание потока:** Реализована синхронизация через `pthread_join()`, благодаря чему родительский поток гарантированно дожидается завершения дочернего перед выводом своего текста.
3. **Параметры потока:** В цикле создаются 4 потока. Каждому потоку через указатель `(void*)` передается свой уникальный набор строк для вывода.
4. **Завершение нити без ожидания:** Добавлена задержка `sleep(1)` между выводами строк. Главный поток через 2 секунды принудительно завершает дочерние потоки с помощью `pthread_cancel()`.
5. **Обработка завершения:** С помощью макросов `pthread_cleanup_push()` и `pthread_cleanup_pop()` зарегистрирован обработчик очистки, который срабатывает в момент отмены потока и выводит диагностическое сообщение в консоль.
6. **Алгоритм Sleepsort:** Реализована нестандартная сортировка массива целых чисел с временной асимптотикой $O(N)$. Каждый элемент массива обрабатывается отдельным потоком, который засыпает на время, пропорциональное значению элемента (`usleep(val * 10000)`), после чего выводит число на экран.
