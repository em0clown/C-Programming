# Отчет по практической работе №17
## Тестирование программного обеспечения

Данный проект содержит реализацию модульных тестов для проверки корректности работы функций обработки строковых данных.

---

### 1. Цель работы
* Покрытие стороннего кода модульными тестами (Unit-tests).
* Использование фреймворка для автоматизации тестирования.
* Вывод результатов тестирования в структурированном и отформатированном виде.

### 2. Описание тестируемого кода
В файле `utils.py` реализована функция `format_username(first_name, last_name)`, которая:
* Объединяет имя и фамилию в одну строку.
* Удаляет лишние пробелы по краям строк с помощью `.strip()`.
* Приводит каждое слово к регистру заголовка (Title Case).
* Возвращает `"Unknown User"`, если один из аргументов пуст или отсутствует.

### 3. Тестовое покрытие
Для тестирования был выбран фреймворк **pytest**. Реализованные тесты в файле `test_utils.py` включают:

| Тест-кейс | Описание | Ожидаемый результат |
| :--- | :--- | :--- |
| `test_format_username_standard` | Обычные строковые данные | `"George Kolesov"` |
| `test_format_username_with_spaces` | Данные с лишними пробелами | `"Ivan Ivanov"` |
| `test_format_username_empty_field` | Одна из строк пустая | `"Unknown User"` |
| `test_format_username_none` | Оба аргумента имеют значение `None` | `"Unknown User"` |

### 4. Результаты выполнения
Запуск тестов осуществляется командой:
```bash
pytest test_utils.py -v
