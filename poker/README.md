# 🃏 Texas Poker (GTK3 / C++)

Локальная игра в Техаcский покер с графическим интерфейсом на базе **GTK 3** и современной системой сборки **CMake**. Поддерживает два режима игры: против искусственного(бота) и локальный мультиплеер за одним экраном (Hotseat).

---

## 🛠 Требования к системе

Для сборки и запуска игры вам понадобятся:
* Компилятор с поддержкой стандарта **C++17** (GCC >= 8 или Clang)
* Система сборки **CMake** (версии 3.28 или выше)
* Инструмент сборки **Make**
* Пакет разработки **GTK 3**

### Установка зависимостей (Ubuntu / Debian / Linux Mint)

Перед сборкой обязательно установите библиотеки GTK3 и утилиты сборки:
```bash
sudo apt update
sudo apt install build-essential cmake libgtk-3-dev pkg-config
```
### Установка зависимостей (macOS)

Для установки библиотек на macOS вам понадобится пакетный менеджер **Homebrew**.

Выполните в терминале:
```bash
# Устанавливаем CMake, компиляторы и GTK+3
brew install cmake pkg-config gtk+3
```
(Опционально) Если вы используете графические приложения в macOS,
убедитесь, что библиотека нативного бэкенда Quartz подхватывается корректно.
