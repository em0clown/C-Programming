# Описание программы "Texas Poker"

## 1. Назначение программы

Программа "Texas Poker" представляет собой компьютерную реализацию популярной карточной игры **Техасский Холдем** (Texas Hold'em). Программа предназначена для:

- Игры в покер против компьютерного бота
- Игры вдвоём на одном устройстве (режим Hotseat)
- Изучения правил и комбинаций Техасского Холдема
- Тренировки навыков игры в покер

## 2. Функциональные возможности

### 2.1. Режимы игры

| Режим | Описание |
|-------|----------|
| **SINGLE_BOT** | Игра против компьютерного противника. Бот принимает решения автоматически на основе силы своей руки и текущих ставок. |
| **MULTI_HOTSEAT** | Два игрока на одном компьютере. Игроки передают устройство друг другу, используя кнопку скрытия карт. |

### 2.2. Игровая логика

Программа полностью реализует классические правила Техасского Холдема:

- **Префлоп** – начальный этап, каждый игрок получает 2 карты
- **Флоп** – на стол выкладываются 3 общие карты
- **Тёрн** – добавляется 4-я общая карта
- **Ривер** – добавляется 5-я общая карта
- **Вскрытие** – определение победителя по лучшей комбинации

### 2.3. Действия игрока

| Действие | Описание |
|----------|----------|
| **ЧЕК / УРАВНЯТЬ (CALL)** | Уравнять текущую ставку или ничего не ставить, если ставок нет |
| **ПОДНЯТЬ (RAISE)** | Увеличить текущую ставку на произвольную сумму |
| **СБРОС (FOLD)** | Сбросить карты и выйти из текущей раздачи |
| **НАЧАТЬ РАУНД** | Начать новую раздачу (списывается анте 10 фишек) |
| **ПОКАЗАТЬ / СКРЫТЬ КАРТЫ** | Переключить видимость карт (для режима Hotseat) |

### 2.4. Распознавание комбинаций

Программа автоматически определяет следующие покерные комбинации (от слабой к сильной):

1. **Старшая карта** (High card)
2. **Пара** (One pair)
3. **Две пары** (Two pair)
4. **Сет** (Three of a kind)
5. **Стрит** (Straight)
6. **Флеш** (Flush)
7. **Фулл-хаус** (Full house)
8. **Каре** (Four of a kind)
9. **Стрит-флеш** (Straight flush)

### 2.5. Логирование

Все действия игроков записываются в файл `poker.log`:
- Смена режима игры
- Начало раунда
- Ставки игроков (Call, Raise)
- Сброс карт (Fold)
- Результаты вскрытия

### 2.6. Система банкротства

- При балансе менее 10 фишек игрок не может начать новый раунд
- Автоматическое восстановление баланса до 1000 фишек при банкротстве
- Визуальное предупреждение (красный цвет) при балансе менее 50 фишек

## 3. Интерфейс пользователя

### 3.1. Графический интерфейс

- **Окно игры** – основное окно размером 980x750 пикселей
- **Стол** – зелёное поле с текстурой (или фоновое изображение table.png)
- **Карты** – визуальное отображение карт игроков и общих карт
- **Информационная панель** – отображение балансов, ставок и текущего банка
- **Статусная строка** – вывод сообщений о ходе игры
- **Кнопки управления** – все игровые действия

### 3.2. Визуальные элементы

| Элемент | Описание |
|---------|----------|
| Карты игроков | Отображаются внизу (Игрок 1) и вверху (Игрок 2/Бот) |
| Общие карты | Отображаются в центре стола |
| Активный игрок | Подсвечивается жёлтым цветом |
| Скрытые карты | Отображаются синей рубашкой |
| Баланс | Красный цвет при низком балансе (< 50 фишек) |

## 4. Логика работы бота

Бот принимает решения на основе двух факторов:
1. **Сила текущей руки** (ранг комбинации)
2. **Размер текущей ставки**

### 4.1. Стратегия бота на префлопе

| Ситуация | Действие |
|----------|----------|
| Слабая рука (макс. ранг < 7, нет пары, ставка > 40) | **Fold** (сброс) |
| Сильная рука (макс. ранг ≥ 12 или есть пара) | **Raise** (рейз +30) |
| Средняя рука | **Call/Check** (колл или чек) |

### 4.2. Стратегия бота на постфлопе

| Ситуация | Действие |
|----------|----------|
| Сильная рука (ранг ≥ 3) | **Raise** (агрессивный рейз +40) |
| Средняя рука (ранг = 2 или ставка = 0) | **Call/Check** |
| Слабая рука (ранг < 2) | **Fold** |

## 5. Технические характеристики

### 5.1. Системные требования


## 6. Архитектура программы

### 6.1. Классы программы

| Класс | Назначение |
|-------|------------|
| **GameState** | Хранит состояние игры: колоду, карты, балансы, ставки, текущий этап |
| **GameView** | Отвечает за графический интерфейс: отрисовка карт, обработка нажатий кнопок |
| **PokerEngine** | Выполняет оценку покерных комбинаций и сравнение рук |
| **Player** | Структура, хранящая данные игрока (имя, деньги, карты) |
| **Card** | Структура, представляющая игральную карту (ранг и масть) |

### 6.2. Взаимодействие классов

```
Main → GameView ←→ GameState ←→ PokerEngine
         ↓
      GTK/Cairo
```

- **Main** инициализирует GTK, создаёт окно и кнопки
- **GameView** обрабатывает действия пользователя и вызывает методы GameState
- **GameState** управляет игровой логикой и вызывает PokerEngine для оценки рук
- **PokerEngine** выполняет вычисления и возвращает результат

## 7. Пример работы программы

### 7.1. Начало игры

1. Пользователь запускает программу
2. Выбирает режим: "С БОТОМ" или "МУЛЬТИПЛЕЕР"
3. Нажимает "НАЧАТЬ РАУНД"
4. Списывается анте (10 фишек с каждого)
5. Раздаются по 2 карты каждому игроку
6. Начинаются торги

### 7.2. Пример раунда

```
Игрок 1: A♠ K♠ (1000 фишек)
Бот: 2♥ 7♦ (1000 фишек)
Банк: 20 фишек

Ход Игрока 1:
> ПОДНЯТЬ до 50 фишек

Ход Бота:
> Бот анализирует свою руку (2♥ 7♦ - слабая)
> Бот принимает решение: FOLD
> Игрок 1 забирает банк 70 фишек
```

### 7.3. Пример вскрытия

```
Борд: 10♥ J♥ Q♥ K♥ 2♠
Игрок 1: A♥ 4♠
Бот: 5♥ 6♣

Результат:
Игрок 1: Роял-флеш (A♥ K♥ Q♥ J♥ 10♥)
Бот: Старшая карта (K♥ J♥ 10♥ 6♣ 5♥)
Победитель: Игрок 1
```

## 8. Ограничения и известные проблемы

- Бот использует упрощённую стратегию (не учитывает позицию за столом)
- Отсутствует мультиплеер по сети
- Нет сохранения прогресса между сессиями
- Требуется ручная установка фонового изображения

## 9. Возможные улучшения

- Добавление сложности бота (лёгкий, средний, сложный)
- Реализация сети для игры с другими игроками
- Сохранение статистики игроков
- Добавление звукового сопровождения
- Анимация раздачи карт
- Поддержка Windows и macOS

## 10. Заключение

Программа "Texas Poker" представляет собой полноценную реализацию игры в Техасский Холдем с графическим интерфейсом, поддержкой двух режимов игры и автоматическим определением победителя. Программа может использоваться для развлечения, обучения правилам покера и тренировки навыков игры.
