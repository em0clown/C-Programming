## 1. Общее описание проекта
Проект представляет собой графический редактор, разработанный на языке **C++** с использованием библиотеки **SFML**. Приложение поддерживает рисование базовых примитивов, работу с цветами, систему отмены действий и применение графических фильтров к холсту.

## 2. Стек технологий
* **Язык программирования:** C++17.
* **Библиотека графики:** SFML (Simple and Fast Multimedia Library).
* **Контейнеры и алгоритмы:** * `std::vector<std::vector<sf::Color>>` - для представления холста.
    * `std::stack` - для реализации истории действий (Undo).
    * `std::transform` и `std::fill` - для обработки пикселей.

---

## 3. Реализованный функционал

### 3.1. Базовые инструменты рисования (Оценка 3)
* **Очистка холста:** Функция `clearCanvas` заполняет рабочую область белым цветом, используя алгоритм `std::fill`.
* **Отрисовка пикселя:** Реализована функция `drawPixel` с обязательной проверкой границ массива `WIDTH` и `HEIGHT`, что предотвращает аварийное завершение программы при рисовании за пределами окна.
* **Кисть:** Инструмент `drawBrush` рисует закрашенный круг. Алгоритм проходит по квадрату $2r \times 2r$ и закрашивает только те точки, расстояние от которых до центра не превышает радиус.
* **Прямоугольник:** Функция `drawRectangle` корректно определяет границы фигуры с помощью `std::min` и `std::max`, позволяя рисовать в любом направлении.

### 3.2. Алгоритмы и управление (Оценка 4)
* **Линия (Алгоритм Брезенхема):** В функции `drawLine` реализован классический целочисленный алгоритм Брезенхема для построения отрезков без использования дорогостоящих операций с плавающей точкой.
* **Система Undo:** Реализована возможность отмены последнего действия (Ctrl+Z). Состояние холста сохраняется в `undoStack` перед каждым значимым изменением (рисование фигуры или применение фильтра).
* **Интерфейс палитры:** * Выбор цвета осуществляется кликом мыши по цветным квадратам в нижней части UI.
    * Поддерживается быстрое переключение цветов клавишами `0-9`.

### 3.3. Графические фильтры (Оценка 5)
Все фильтры реализованы с использованием итераторов и лямбда-выражений:
* **Grayscale:** Перевод изображения в оттенки серого по формуле яркости.
* **Negative:** Инверсия каждого цветового канала ($255 - x$).
* **Blur:** Фильтр размытия 3x3, вычисляющий среднее арифметическое цветов соседних пикселей.
