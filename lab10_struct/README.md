## 📋 Описание проекта
Программа на языке C для анализа квадратичных функций вида **y = ax² + bx + c**. Программа определяет:
1. Количество парабол, имеющих минимум (ветви направлены вверх)
2. Находит среди них параболу с наибольшим значением минимума
3. Выводит подробную информацию о найденной параболе

### 🛠️ Реализованные функции

1. **Создание парабол**
```c
Parabola createParabola(double a, double b, double c);
```
Создает структуру параболы с заданными коэффициентами.
```c
Parabola* createParabolas(int M);
```
Динамически создает массив из M парабол, запрашивая коэффициенты у пользователя.

2. **Анализ парабол**

```c
int hasMinimum(Parabola p) {
    return p.a > 0; 
}
```
Проверяет, имеет ли парабола минимум (a > 0).

```c
double getMinValue(Parabola p);
```
Вычисляет значение минимума параболы по формуле:
```text
x = -b / (2a)
y = a*x² + b*x + c
```

3. **Обработка массивов**
```c
int countParabolasWithMin(Parabola* parabolas, int M) {
    int count = 0;
    for (int i = 0; i < M; i++) {
        if (hasMinimum(parabolas[i])) {
            count++;
        }
    }
    return count;
}
```
Считает, сколько парабол в массиве имеют минимум.
```c
int findHighestMinParabola(Parabola* parabolas, int M) {
    int maxIndex = -1;
    double maxMinValue = -1e9; 
    
    for (int i = 0; i < M; i++) {
        if (hasMinimum(parabolas[i])) {
            double currentMin = getMinValue(parabolas[i]);
            if (currentMin > maxMinValue) {
                maxMinValue = currentMin;
                maxIndex = i;
            }
        }
    }
    
    return maxIndex;
}
```
Находит индекс параболы с наибольшим значением минимума.
